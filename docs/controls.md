# Controls

- WASD or arrow keys: move
- Shift: sprint
- Space: jump or rise in flight mode
- F: toggle flight mode
- E: throw a physics crate
- Mouse: look around
- Escape: release or recapture the cursor and toggle the menu

## Multiplayer
Host World starts an ENet server on UDP port 27015. Join World connects to a reachable server address. Internet sessions require inbound UDP access and suitable firewall or router configuration.
